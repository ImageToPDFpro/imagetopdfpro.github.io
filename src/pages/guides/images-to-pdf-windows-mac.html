Windows and macOS both include tools that can turn images into a PDF without downloading anything. They're handy to know, especially when you're offline on an unfamiliar computer. This guide walks through each method, explains the settings that trip people up, and helps you decide when a dedicated converter is the better option.

Windows 10 and 11: Microsoft Print to PDF

Windows includes a virtual printer called Microsoft Print to PDF. Instead of sending pages to paper, it saves them as a PDF file.

Step by step

  1. Open File Explorer and go to the folder with your images.
  2. Select the images. Hold Ctrl and click to choose several, or press Ctrl + A to select all.
  3. Right-click the selection and choose Print. On Windows 11, if you don't see it, choose Show more options first.
  4. In the Print Pictures window, set Printer to Microsoft Print to PDF.
  5. Choose the paper size (for example A4 or Letter) and a layout from the list on the right. Full page photo places one image on each page.
  6. Untick Fit picture to frame if you don't want the edges of your images cropped.
  7. Click Print, choose a file name and location, and click Save.

Watch out for cropping: "Fit picture to frame" is ticked by default. It fills the page by cutting off parts of the image that don't match the page shape, which can remove the edges of a document or ID card.

Can't find Microsoft Print to PDF?

It can be turned off. Search the Start menu for Turn Windows features on or off, tick Microsoft Print to PDF and click OK.

Limitations on Windows

  • Page order follows the order of the files in the folder, which is hard to control without renaming files.
  • There is no way to rotate individual images in the print dialog.
  • HEIC photos from an iPhone need the HEIF extension from the Microsoft Store before Windows can print them.
  • There's no compression option, so PDFs from phone photos can be very large.

macOS: Quick Actions (fastest)

Since macOS Mojave, Finder can create a PDF from images in two clicks.

  1. In Finder, select your images. Hold ⌘ and click to choose several.
  2. Right-click (or Control-click) the selection.
  3. Choose Quick Actions → Create PDF.

A new PDF appears in the same folder, named after the first image. Pages follow the order of the files in the Finder window, so sort the window by name first if order matters. Each page takes the size of its image.

macOS: Preview (more control)

Preview lets you reorder pages and choose a paper size.

  1. Select your images in Finder, right-click and choose Open With → Preview.
  2. If the sidebar isn't visible, choose View → Thumbnails.
  3. Drag thumbnails in the sidebar to reorder. To rotate an image, select it and press ⌘ + R.
  4. Click a thumbnail and press ⌘ + A to select all images.
  5. Choose File → Print (⌘ + P).
  6. Set the paper size and choose Scale to Fit: Print Entire Image to avoid cropping.
  7. Open the PDF menu at the bottom of the dialog and choose Save as PDF.

Tip: In the print dialog, "Fill Entire Paper" crops images to cover the page, similar to "Fill page" in our converter. "Print Entire Image" keeps the whole picture.

ChromeOS and Linux

Open an image in the browser or the Gallery app, press Ctrl + P and choose Save as PDF as the destination. This works well for single images. For multiple images, a browser-based converter is much quicker.

Frequently asked questions

Does printing to PDF reduce image quality?

It can. Virtual printers may resample images to the printer resolution. If image quality is critical, use a tool that embeds the original image data, such as our converter at Original quality.

Why is my PDF blank or missing pages?

This usually means an image format the system can't read, such as HEIC on Windows without the extension, or WebP in older software. Convert those images first, or use a browser-based converter that supports them.

Can I do this on a work computer without admin rights?

Yes. All the methods in this guide, and our online converter, work without installing anything.
